# Змейка для телефона

Классическая «Змейка» на чистом HTML5 + CSS3 + JavaScript. Без сборки, без npm, без бэкенда, работает офлайн после загрузки.

## Управление

- Телефон: свайпы по полю или кнопки-стрелки под полем.
- ПК: стрелки или WASD. Пробел или Enter запускают игру.
- Игра ставится на паузу при сворачивании вкладки. Любое нажатие управления возобновляет её.

## Как запустить через GitHub Pages

1. Зайди на [github.com](https://github.com) и войди в аккаунт (или зарегистрируйся).
2. Нажми **New repository**, введи имя (например, `snake`), выбери **Public** и нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file** (или **Add file → Upload files**).
4. Перетащи в окно четыре файла: `index.html`, `style.css`, `game.js`, `README.md`.
5. Нажми **Commit changes**.
6. Открой **Settings → Pages**.
7. В разделе **Build and deployment** выбери **Source: Deploy from a branch**, затем **Branch: main** и папку **/ (root)**, нажми **Save**.
8. Подожди 1–2 минуты и обнови страницу настроек. Вверху появится ссылка.

Игра откроется по адресу:

```
https://ТВОЙ_НИК.github.io/ИМЯ_РЕПОЗИТОРИЯ/
```

Открой ссылку на телефоне. Чтобы играть как в приложении, в Safari выбери «Поделиться → На экран Домой», в Chrome — меню → «Добавить на главный экран».

## Структура

```
/
├── index.html   разметка
├── style.css    оформление
├── game.js      логика игры
└── README.md    эта инструкция
```

## Настройки

В начале `game.js` можно менять размер поля (`GRID`), начальную скорость (`START_DELAY`), максимальную скорость (`MIN_DELAY`) и прирост скорости за еду (`SPEEDUP`).
